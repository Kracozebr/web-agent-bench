# Mode: Piecemeal growth

Grow the benchmark from requirements, observed agent behavior, and failures that have actually
occurred. Keep the implementation narrow to the current contract; do not add speculative scoring
dimensions, chain adapters, concurrency modes, or fallback paths merely because they might be useful
later.

Generalize after repeated evidence shows what the generalization must support. This does not weaken
integrity at real boundaries: protect durable evidence, external callers, keys, funds, and match
fairness where the demonstrated risk or cost requires it.
